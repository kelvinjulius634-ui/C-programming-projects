# C Programming Projects

A collection of small C programs written while learning core programming concepts — functions, control flow, structures, and I/O.

## Programs

- **Grades.c** — Calculates the average of a student's marks and determines Pass/Fail based on a 60% threshold.
- **simple_calculator.c** — A menu-driven calculator supporting add, subtract, multiply, and divide using functions and switch-case.
- **decimal_binary_converter.c** — Converts a decimal number to its binary representation.
- **learn_structure.c** — Demonstrates the use of `struct` in C to group related data.

## How to compile and run

Using GCC:
```bash
gcc filename.c -o output
./output
```
Using Clang (e.g. on Termux):
```bash
clang filename.c -o output
./output
```
